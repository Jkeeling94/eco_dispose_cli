# EcoDispose CLI

EcoDispose CLI is a Python-based command-line application designed to guide users through responsible electronic waste disposal in line with WEEE regulations.

---

## What is WEEE?

WEEE stands for *Waste Electrical and Electronic Equipment*. These regulations ensure that electronic devices are disposed of safely and responsibly to reduce environmental impact and prevent environmental harm

---

## Features

- Domestic and Commercial user pathways
- Device type validation from a supported list
- Data removal checks before disposal
- Device condition handling (Working / Broken)
- Tailored disposal guidance including:
  - Recycling centres
  - Retailer take-back schemes
  - Manufacturer return options
  - Licensed WEEE providers
- Council-specific recycling links
- Input validation using loops
- Error handling with `try/except`
- GDPR-conscious design (no permanent data storage)
